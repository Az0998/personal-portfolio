# 智慧水利作品集 · QA Checklist

面向导师 / 设计院面试演示。失败项按 **P0 → P1** 修；本文件可手测，亦可跑可选 Playwright 冒烟。

## 快速约定

| 优先级 | 含义 |
|--------|------|
| **P0** | 阻塞演示：首页职业方向、主 CTA、主链入口、底图水印、脏数据、导航不可用 |
| **P1** | 体验/可信度：测距、NSE 联动、Word 声明、横滑、aria、LCP |

锁定作品：后台勾选「保护已保存内容」后，`npm run sync` / 默认同步**不会**覆盖正文与封面。见 Admin 同步面板说明。

---

## 1. 首页（P0）

- [ ] **3 秒内**可见职业方向：姓名 +「智慧水利 / 水信息」+ 链路文案「采集 → 空间 → 态势 → 预报 → 文档」
- [ ] 主 CTA「进入智慧水利」→ `/hydrobench`
- [ ] 精选区仅主链 5 项 + 可选 Hydro-ML；**无**问卷 / 象棋 / Novel 等 demo 占首屏
- [ ] 主链卡片有「链路 n/5」与子标签（工具/空间/态势/模型/文档）
- [ ] 联系邮箱非占位；地点为「兰州（意向：南京 / 广州）」

## 2. 智慧水利总览（P0）

- [ ] 五个主链入口都在（作业 / 空间 / 态势 / 模型 / 文档）
- [ ] 「5 分钟导览」可走通 step 1→5 → done
- [ ] 移动端顶栏可开合；步骤条可横滑

## 3. 流域一张图（P0/P1）

- [ ] **P0** 底图无「API KEY REQUIRED」水印（Esri / OSM 零密钥）
- [ ] **P1** 点击空白测距：地图黄虚线 + 侧栏距离
- [ ] 图层开关后空间统计随之变化
- [ ] 站点过程线可跳转 HydroInfo

## 4. 新安江对照台（P1）

- [ ] 改 **K** 后过程线重绘，NSE（暖期后）变化
- [ ] 「恢复率定值」可用，指标回落
- [ ] 暖期带可见（窗口选「全部」）
- [ ] 可导出参数 JSON / 过程线 CSV

## 5. 水平衡论证（P0/P1）

- [ ] **P0**「清空」后无脏案例数据残留
- [ ] 示例案例平衡差 ≈ 0 可导出
- [ ] **P1** Word / Markdown 含「非正式 / 演示草稿」声明
- [ ] 退水 > 取水：硬阻断提示，不可当正式导出

## 6. 作品详情（P1）

- [ ] 底部为「主链上下游」推荐，非随机相关
- [ ] 模型步可见 Hydro-ML 对照入口

## 7. 移动端 / 无障碍 / 性能（P1）

- [ ] 导航汉堡按钮有 `aria-label`；关键图标按钮同理
- [ ] 图表区域可横滑（态势 / 作业条）
- [ ] 正文与按钮对比度可读（白字 / 青绿强调）
- [ ] 首屏 LCP 可接受（Hero 无超大阻塞图）
- [ ] 大 GeoJSON 不卡死 UI（加载态可见）
