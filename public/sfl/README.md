# 微型蒸渗仪数据处理（`/sfl`）

浏览器端处理 SmartField / SFL 的 DT80 CSV：质控标记 + 10 分钟降水 + 午夜蒸散。个人站页面：https://zhangsjqaq.vexr.dev/sfl/

## 重要说明

1. **合成示例 ≠ 现场结论**。「用示例序列」只用于演示界面与交互；正式验收、阈值校准、答辩数据请用真实 DT80 导出。
2. **旧 Python 路径已废弃**。早期本地服务（`localhost:8765` / `sfl-platform`）不要再混用；以本目录静态页为真源。
3. **不要与 `hydro-info-platform` 混淆**。那是流域水文看板；本工具是蒸渗仪专用前端，尚未合并进该仓。
4. **碰壁启发式默认关闭**。未用真实长序列校准前，合成数据上易大片误标；需要时再勾选「启用碰壁检测」，且结果仅作诊断。
5. **AWAT / snap 尚未接入**。过滤前后对比待处理笔记公式落地后再做。

## 本地打开

```bash
cd public/sfl   # 或本目录
python -m http.server 8766
# 浏览器打开 http://127.0.0.1:8766/
```
