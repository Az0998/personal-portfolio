# Pixiv 背景图（请自行放入）

参考站 [哒哒的博客](https://www.dayabolg.top/) 使用全屏二次元插画作「一图流」背景。

**请勿直接盗用他人 Pixiv 作品。** 仅使用你已获得授权 / 可商用 / 自己绘制的图片。

## 用法

把横图放到本目录，并命名为：

- `hero.jpg`（或 `hero.png` / `hero.webp`）— 全站固定背景，优先于默认图

站点会按此顺序选用背景：

1. `/media/pixiv/hero.jpg|png|webp`（你放的图）
2. `/media/bg/hero-loli.jpg`（默认 ACG 壁纸兜底）

建议分辨率 ≥ 1920×1080，人物主体偏右或偏上，便于左侧/中部叠字。
