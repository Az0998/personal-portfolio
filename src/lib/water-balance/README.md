# 水平衡演算口径（演示）

本页是**室内岗草稿工具**，不是水资源论证法定文本，不能替代评审或取水许可。

## 主口径（只保留这一套）

符号：取水 `Q`，退水 `R`，管网/未计量损失 `L`，分项需水 `Qi`。

| 量 | 定义 | 说明 |
|----|------|------|
| 需水合计 `D` | `D = Σ Qi` | 由表内分项加总，不另开「表外合计」 |
| 耗水 `C` | `C = Q − R` | **唯一耗水口径**。不是「工艺耗水 / 定额耗水」 |
| 平衡差 `Δ` | `Δ = Q − (D + L)` | 供给闭合：取水应等于需水加损失 |
| 闭合 | `\|Δ\| < 0.005`（显示到 0.01） | 差不为 0 **禁止**写「闭合」；空表为「待计算」 |

退水 `R` **不进入**平衡差。`R` 只用于耗水与退水率：`C/Q`、`R/Q`。

关系拆开写，避免混成一条假恒等式：

```
Q = D + L + Δ          （配置/供给闭合）
C = Q − R              （耗水，水量去向）
```

`Δ ≠ 0` 时：正值 = 取水未分解完；负值 = 需水+损失超过取水。

## 单位

- 默认 **万m³/a**
- 可切 **m³/d**
- 换算固定 **365 日/年**：`1 万m³/a = 10000 / 365 ≈ 27.40 m³/d`
- 切换时全部水量字段一起换算，并提示复核取整

## 需水表

- 可增删行；`D` 随 Σ 实时变
- 校验行：`分项之和 − 需水合计`，按定义应为 0；若出现非零即实现错误

## 示例（万m³/a）

`Q=120，D=12+86+10+4=112，L=8，R=48`

- `Δ = 120 − (112+8) = 0` → 可写闭合
- `C = 120 − 48 = 72`，退水率 40%

## 改动点（相对初版演示）

1. **一口径**：耗水只认 `C = Q − R`，不再混用「工艺耗水」；Δ 不含退水。
2. **公式卡**：输入区旁展示 `D` / `C` / `Δ` 定义与闭合阈值。
3. **单位**：全站 `万m³/a` 或 `m³/d`，输入旁标注；切换按 365 日换算并提示复核取整。
4. **需水表**：可增删行；分项之和与需水合计实时对照，超差写出具体差。
5. **状态**：空表为「待计算」；`|Δ| ≥ 0.005` 时 KPI 标红，文案禁止「闭合」。
6. **载入示例 / 清空**：每次克隆新对象并重算右侧报告，避免残留旧文案。
7. 徽章保持 **演示草稿 · 非正式论证**。
